# v1.10.0

## What's Changed

### 🔍 Troubleshoot

- feat: Event Resolutions is now its own tab under Troubleshoot
- feat: Filter events by triage priority (P0–P3)
- feat: Event list buttons now say "View Analysis" once an analysis is ready
- feat: Blast radius now covers volumes, load balancers, and VM callers, and shows each dependent's criticality, how recently it was used, and its restart risk
- feat: A safety rating, graded by type of change, is shown wherever you apply a fix, together with the action it recommends
- feat: Noisy Neighbours now covers CPU contention and shows CPU usage on its card
- fix: Investigations into a past time now query the selected time window instead of the last few minutes
- fix: Investigations now check the exact pod a finding is about, using evidence from around the time it failed
- fix: A pod's alert stays open while its rollout is stuck
- fix: Log lookups no longer hide or narrow evidence during an investigation

### 📊 Dashboards

- feat: New read-only kubectl data source for dashboard panels
- feat: Stat and gauge panels change colour when they cross a threshold
- feat: Import a dashboard by uploading a `.json` file

### ⚡ Optimization

- feat: The Optimize summary widget now shows real data, and you can filter it and click through to details
- feat: Assign a resource owner directly from the Optimize drawer
- fix: Right-sizing that raises cost is now shown as a cost increase instead of zero savings
- fix: Azure volume savings are priced by the billed disk tier instead of a flat rate
- fix: Corrected the GCP Hyperdisk Balanced storage rate
- fix: Idle Elastic IPs now show their real savings instead of $0
- fix: More accurate RDS pricing by license, edition, and storage setup, plus savings from reserving instances
- fix: Log-group retention recommendations now show how much storage they would free and where the price came from

### 🔄 Workflow

- feat: New trigger simulator in the automation builder to test triggers before saving
- feat: Click-to-fill examples and syntax help in action fields
- feat: New Application Diagnostic Check runbook template
- feat: Attach an automation's output as evidence on an existing event, and choose the type of evidence
- feat: Script steps can run with the credentials of the account they name
- fix: Saved credentials are no longer shown in full on the automation run screen
- fix: PR follow-ups stop when the PR is closed or gets too old
- fix: Fixed workflow server startup failures and crashes

### ☸️ Kubernetes

- feat: Connect Prometheus and Loki directly, without a NudgeBee agent in front of them, including creating and receiving Prometheus alerts
- feat: Agent Details now shows the status of log, metric, and trace providers that don't run through an agent
- fix: Agent status is now reported consistently across the product
- fix: Improved relay reliability; the relay now returns "Service Unavailable" when the agent is offline
- fix: Better startup resilience and memory limits across services to prevent crashes and out-of-memory restarts

### ☁️ Cloud

- feat: The AWS Cost & Usage Report (CUR) is now optional during onboarding
- feat: Remediation suggestions now work on cloud accounts as well as Kubernetes, and generated cloud commands can be run directly
- fix: AWS events are now linked to the right resource so they correlate correctly, and each alarm creates a single event
- fix: CloudWatch alarm evidence now matches what the alarm reports
- fix: Agents stay connected when cost data is not set up, and missing CUR permissions are shown as "not configured" instead of an error
- fix: NudgeBee now sends an External ID when assuming a role in your AWS account
- fix: Data from disabled cloud accounts is no longer collected
- fix: Faster Lambda discovery

### 🤖 AI

- feat: Answer confidence scoring grades investigation answers after they're complete (enabled per tenant)
- feat: See what the secret filter detected in outgoing data, where it came from, and what it was replaced with
- feat: Actions now record what they changed, so they can be undone, and remediation commands record whether they were verified
- feat: The reasoning (thinking) switch is now available on custom LLM configurations
- feat: The code agent supports custom LLM providers
- feat: Nubi can search NudgeBee product documentation and give more reliable answers about agent and data-source health
- feat: Large knowledge documents load reliably, and code blocks, tables, and Confluence page titles are now indexed
- feat: Agents are listed under their catalog names in a cleaner layout
- feat: The new logs agent is now the default; the legacy logs agent has been removed
- fix: The GitLab agent now acts only on the intended project, user, and security setting
- fix: Stricter safety checks on shell and cloud commands before approval
- fix: Event analysis pauses while waiting for approval and resumes correctly afterwards
- fix: Fixed prompt caching for Gemini Flash models
- fix: The weekly review completes even in busy weeks
- fix: The time-saved tile no longer drops to zero because of stale data
- fix: Ask NudgeBee no longer crashes on malformed clarification requests
- fix: Faster webhook processing with much lower LLM token use

### 🔔 Notifications

- fix: Slack now shows an in-progress indicator for watches and posts the result when they finish
- fix: The Slack "Thinking" panel stays open correctly during an investigation
- fix: Line breaks now display correctly in Slack tables
- fix: Fixed duplicate and outdated conversations in automated notifications

### 🎫 Tickets

- fix: Fixed a Jira project sync loop that could crash the ticket server

### 🔌 Integrations

- feat: Map trace field names in Settings, per integration, and see which mapping takes priority
- feat: Set a standing filter that applies to every trace search for an account
- feat: Log field concepts are now named the same way as in the trace panel
- feat: The Integrations grid shows the default logs, traces, and metrics provider
- feat: Reference agents and tools inline in the Knowledge Base form

### 🛡️ Admin & Platform

- feat: Admin has been reorganised into **Access & Users** and **Tenant Settings**, and b-Cortex is grouped into Memory, Knowledge, Knowledge Graph, and Insights
- feat: Feature flags appear in a table, with reset and navigation for each flag
- feat: Branding is applied per tenant domain, replacing hard-coded NudgeBee text
- feat: SAML sign-in requests are signed when a signing key is configured
- feat: You are warned before removing Knowledge Graph coverage, and every settings change is audited
- feat: Global search has tidier sections and better Suggested Pages
