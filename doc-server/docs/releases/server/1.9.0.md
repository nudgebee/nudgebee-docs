# v1.9.0

## What's Changed

### 🔍 Troubleshoot

- feat: Group alerts firing together into correlated incidents and prevent relationship drops during alert storms
- feat: Introduce generic, bounded Elasticsearch metric reader supporting aggregation responses and dynamic datatypes by default
- feat: Provide root cause diagnostics when trace queries match zero spans and capture uncertain classifications for review
- feat: Display executed provider queries directly on log evidence cards and add dismiss controls to theme heuristic banners
- fix: Unify event remediation into a single execution path with persistent action records
- fix: Improve incident grouping accuracy and blast-radius impact calculation
- fix: Close events for deleted resources by specific resource ID and prevent the resolution pass from clearing event severity
- fix: Resolve Elasticsearch metric label query errors, strip customer identifiers, and preserve multiple metric shapes
- fix: Resolve canonical OpenTelemetry trace fields server-side and limit advertised fields to supported provider attributes

### ⚡ Optimization

- feat: Generate workload cost allocation and rightsizing recommendations for clusters without Prometheus
- feat: Apply automated AWS EBS gp2 to gp3 volume upgrades directly via asynchronous ModifyVolume operations
- feat: Enhance Optimize UX with row actions on Configuration findings, finding counts on Security sub-tabs, and reorganized Resolutions placement
- feat: Add rollup-mode filtering and per-account breakdown splits to the Configuration tab
- fix: Price Persistent Volume cost allocation and PVC savings by cloud storage class (including GCP Hyperdisk Balanced) instead of flat rates
- fix: Compute Persistent Volume rightsizing recommendations directly from Elastic Agent storage metrics
- fix: Drop no-op rightsizing recommendations where suggested CPU and memory remain unchanged
- fix: Protect EBS volume upgrade recommendations against silent downgrades and unsupported target regions
- fix: Display non-additivity savings warnings directly inside FinOps optimization tables

### 🔄 Workflow

- feat: Link automations and generated events directly to investigated incident records and surface execution history on remediation cards
- feat: Add Copy Link and Copy JSON quick actions to the Automations table menu
- fix: Ensure unique automation name resolution across workflow filters and dry-run execution views
- fix: Distinguish unregistered domains from network lookup failures in DNS and WHOIS workflow tasks
- fix: Optimize Automation builder performance by trimming tool-loop history and reading failures directly from cached records

### ☸️ Kubernetes

- feat: Bundle the NudgeBee agent in Helm charts with default installation, pre-provisioned admin credentials, and an agent-only onboarding path
- feat: Add Change Environment action to Kubernetes cluster account cards
- fix: Resolve credential parsing bug that clipped the leading character in agent authentication tokens
- fix: Route webhook callbacks through the application Nginx sidecar rather than the external ingress
- fix: Resolve discovery agent vulnerability scanning issues on self-hosted VMs

### ☁️ Cloud

- feat: Construct cloud topology from pre-synced resource inventories instead of running on-demand CLI queries
- fix: Improve AWS resource synchronization by enumerating standalone ECS tasks per cluster and matching EventBridge identity keys
- fix: Scope GCP log-alert evidence strictly using the filter configured on the alerting policy
- fix: Respect AWS region allowlists and resolve unreadable Cost and Usage Report (CUR) parsing errors
- fix: Display cloud service names instead of Kubernetes namespaces for cloud-account event triggers

### 🤖 AI

- feat: Add native Anthropic adapter with thinking parameter controls on AWS Bedrock (where bare model IDs are valid for on-demand inference within the same region, though inference profiles are recommended for cross-region routing and availability) and Direct API connections
- feat: Introduce Nubi self-awareness agent for platform capabilities, navigation, and system status inquiries
- feat: Support GPT-5.6, prompt caching, tool schema serialization, and alias authorization in ReAct-4
- feat: Gate LogsV3 as a selectable default logging agent and callable tool for parent orchestrators
- feat: Score Knowledge Base relevance with a bfloat16 cross-encoder reranker and cap content size at 5,000 characters
- feat: Allow tenants to selectively exempt agents from egress secret detection, support soft cancellations for follow-ups, and support LLM_CONFIG_IGNORE_DB overrides
- feat: Enable remediation follow-up agent to track addressed PR comments and synchronize outdated PR branches
- fix: Prevent RAG server out-of-memory crashes by bounding cross-encoder reranker concurrency and aligning default model weights
- fix: Honor explicit per-tier LLM configurations, log serving providers, and merge consecutive system messages for OpenAI-compatible endpoints
- fix: Gate destructive shell commands and tool wrappers behind explicit human-in-the-loop risk confirmation
- fix: Harden agent workspace sandbox security by blocking unauthorized secret reads, eliminating shared API key injection, and enforcing stricter container baselines
- fix: Ensure GPT-5.x models invoke real-time tools for short live-state queries in ReAct-3 mode and prevent empty argument payloads
- fix: Restore event_get_triage RPC action and prevent crashes on oversized trace and label evidence in triage agents
- fix: Scope automated code-fix generation tightly to localized diffs produced by the debug agent
- fix: Resolve model output formatting and reasoning trace handling for Qwen models

### 🔔 Notifications

- feat: Enable direct messaging (DM) to Nubi in Slack without @mentions and stream live investigation updates to notification cards
- feat: Add per-tenant scheduling and dedicated Slack channels for AI Cost Reports
- feat: Add deep links to insight rows in daily highlight emails and rename Admin Notifications to Notification Rules
- fix: Deliver Ask Nubi to Analyse clarification prompts directly to Slack threads and render Mermaid flowcharts cleanly
- fix: Filter non-critical events from daily summary emails and fix formatting for high-frequency email insights

### 🎫 Tickets

- feat: Jira Data Center support with Personal Access Token (PAT) authentication, ticket creation, and status synchronization

### 🔌 Integrations

- feat: Allow administrators to restrict Confluence knowledge indexing to specific page trees
- feat: Support custom log integration field mappings with transparent precedence resolution
- feat: Add human-readable names, logical grouping, and default state definitions to tenant feature flags
