# v1.11.0

## What's Changed

### 🔍 Troubleshoot

- feat: ConfigMap changes are now linked to the workloads that read them, and Ingress changes to the workloads they route to
- feat: OOMKill investigations now show the memory usage leading up to the kill
- feat: A workload's alerts close automatically once all its pods are ready again
- feat: Alerts for deleted resources are now closed on a regular schedule, not only at the time of deletion
- feat: Pod CPU and memory, impacted services, threshold history, and alert labels now work with any configured metrics provider, not just Prometheus
- feat: Switch the metrics provider directly from the Query Metrics badge and the Cloud Metrics tab
- feat: Count pods and find the busiest pod using Elasticsearch data
- feat: Event enrichment now runs in the background by default, so events appear faster
- fix: Investigations now point to the right deployment change, and you can choose which change to revert
- fix: Each correlated change is now named, instead of showing several identical rows
- fix: Repeated pressure alerts from a flapping node are grouped into a single problem
- fix: Alerts that the cluster agent reports as resolved now close in NudgeBee
- fix: Cloud alarms now connect to their backend services in the service map

### 📊 Dashboards

- feat: Per-cluster thresholds, breakdowns, and JSON editing for dashboard panels
- feat: Filter traces and NudgeBee panels by their columns
- feat: Set a panel's unit from the panel editor

### ⚡ Optimization

- feat: Dismiss, snooze, or reactivate findings on every Security tab
- feat: Assign an owner from the Security finding drawer and from Cloud Posture rows
- feat: Ask Nubi about any Security finding
- feat: Copy the CLI command for Cost rules with a fully defined action
- fix: Reliability and hygiene findings have moved out of the Cost tab
- fix: Pod rightsizing savings now account for the average replica count over the time window
- fix: Multi-container workloads now show both what they save and what they cost, not only the net figure
- fix: Optimization scores refresh daily, and new recommendations are scored hourly

### 🔄 Workflow

- feat: Automations can be set to run without asking for confirmation
- fix: Automation steps that the cluster agent refuses are now marked as failed
- fix: Steps now wait for all their dependencies, including matrix steps

### ☸️ Kubernetes

- feat: Set the storage class once for the whole install
- feat: Install on clusters that don't have the Prometheus Operator
- feat: The Kubernetes install step waits until the agent connects
- feat: Turn image scanning off for an account or a namespace
- feat: See when the agent last reported its health, and a clearer cluster health tooltip
- fix: Faster metric queries through the relay, and lower memory use across services

### 🤖 AI

- feat: Queue follow-up messages while an investigation is still running, with controls to manage the queue
- feat: The FinOps agent can dismiss, snooze, or reactivate a recommendation after you confirm; it now answers all recommendation questions
- feat: Prompt overrides can be set per model instead of per provider
- feat: Custom Knowledge Base tags are used when finding relevant knowledge
- feat: Improved code agent workflows and smoother hand-offs from investigations
- fix: Irreversible cloud operations are blocked during remediation
- fix: Stronger agent workspace security with a read-only file system
- fix: LLM providers that were never assigned to an account are no longer selected automatically
- fix: Test Connection now works for thinking models in LLM configuration
- fix: Prompt caching restored for long answers across Gemini and Anthropic models, reducing cost and response time
- fix: More reliable investigations with Qwen models
- fix: Conversations started from JSON alerts now get readable titles
- fix: Canceling an analysis now stops it cleanly

### 🔔 Notifications

- feat: Microsoft Teams channel webhooks as a notification target
- feat: Channel mapping conflicts now name the account or tenant that already uses the channel
- fix: Clearer trend markers and rightsizing labels in the daily recap
- fix: The AI Cost Report hides the trend when there is no earlier data to compare with
- fix: Links in the events summary email now open the Events tab
- fix: Follow-up questions in event investigation channels are routed correctly
- fix: Bot replies and emails use your tenant branding, and Slack threads no longer show link previews
- fix: The Sign In button in magic-link emails is easier to read
