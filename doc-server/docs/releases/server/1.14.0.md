# v1.14.0

## Before You Upgrade

### All editions

- **LLM defaults are now explicit:** An account uses its own default LLM, then the organization default, then the platform model. NudgeBee no longer guesses from how many configs an account has. If an account's only LLM config isn't marked as its default, the account switches to the organization default when you upgrade. Check your defaults in **Settings → Integrations → LLM** before upgrading. Changes that would leave accounts without a model are now flagged, and refused when there is no platform model.
- **Alert investigations run read-only:** Automatic investigations, and Generate or Regenerate RCA, no longer stop to ask for approval. They refuse changes and collect evidence in a read-only way instead. Chat follow-ups still ask for approval. Alert and automation conversations that are waiting for an answer now expire after 12 hours.
- **Nubi asks before writing to ticketing tools:** Creating tickets, adding comments, updating ticket fields, and creating automations from chat now require approval.

### Community edition

- **Service tokens are required:** services-server and cloud-collector now return `503` when their service token isn't set, and `401` when a request has a missing or wrong token. The Helm chart generates these tokens. Custom deployments must set `ACTION_API_SERVER_TOKEN` and `CLOUD_COLLECTOR_SERVER_TOKEN`.
- **services-server endpoints:** Only the exact `/health` path is public. Profiling endpoints now require the service token.
- **Demo account removed:** The sample-data Demo account no longer appears in the account switcher. A tenant with no connected accounts now sees an empty switcher.
