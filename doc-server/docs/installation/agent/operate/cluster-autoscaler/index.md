# Cluster Autoscaler

NudgeBee detects the node autoscaler running in the cluster — [Karpenter](https://karpenter.sh/), the Kubernetes Cluster Autoscaler, or GKE autoscaling — and shows it under **Optimize → Auto Scaler**. Karpenter gets the most views (node pools and node classes). See [Kubernetes → Auto Scaler](../../../../features/Kubernetes/autoscaler.md).
