# Action: Terminate Node Gracefully

:::note Moved to Automations
This action is now the `k8s.node_graceful_shutdown` task in the Workflow Builder. Add it to an automation with **Add Action** and configure it there — see **[Node Graceful Shutdown](../../../workflow-builder/kubernetes-tasks.md#k8snode_graceful_shutdown)** for its parameters and output.
:::

To apply right-sizing automatically on a schedule or continuously, use [Auto Optimize](../auto_optimize/index.md) instead.
