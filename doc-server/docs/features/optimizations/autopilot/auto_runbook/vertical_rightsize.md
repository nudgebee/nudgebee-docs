# Action: Vertical Rightsize

:::note Moved to Automations
This action is now the `k8s.vertical_rightsize` task in the Workflow Builder. Add it to an automation with **Add Action** and configure it there — see **[Vertical Rightsize](../../../workflow-builder/kubernetes-tasks.md#k8svertical_rightsize)** for its parameters and output.
:::

To apply right-sizing automatically on a schedule or continuously, use [Auto Optimize](../auto_optimize/index.md) instead.
