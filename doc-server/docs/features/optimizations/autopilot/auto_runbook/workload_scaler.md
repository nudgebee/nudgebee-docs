# Action: Resource Scaler

:::note No longer available
The Resource Scaler action is no longer available. To change a workload's replicas from an automation, use the **[Horizontal Rightsize](../../../workflow-builder/kubernetes-tasks.md#k8shorizontal_rightsize)** task, or set up [Horizontal Right Sizing](../auto_optimize/index.md) in Auto Optimize.
:::
