# Action: Execute Image

:::note No longer available
Running a custom container image as an automation action is no longer available. To run your own logic in an automation, use the **[Run Script](../../../workflow-builder/scripting-tasks.md#scriptingrun_script)** task, or give NuBi a [custom tool](../../../ai/custom-tools.md) that runs your image.
:::
