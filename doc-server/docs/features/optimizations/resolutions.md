# Optimize → Resolutions

**Optimize → Resolutions** lists every attempt to resolve a recommendation, across all accounts — fixes applied from the Optimize pages, pull requests, tickets and Auto Optimize runs.

The cards at the top are the status filter: **All Resolutions**, **Success**, **In Progress** and **Failed**. You can also filter by **Account**, **Severity**, **Type** and **Resolver**.

| Column | Meaning |
|---|---|
| **Account** | Where the recommendation is |
| **Recommendation** | What was resolved, with a link to the pull request or ticket when there is one |
| **Severity**, **Status** | The recommendation's severity, and how the attempt went |
| **Est. Savings** | The expected saving |
| **Resolver**, **Type** | Who or what resolved it, and how |
| **Updated At** | Last change |

A **Failed** row has a **Retry** button. Creating a ticket from a recommendation also adds a row here.
